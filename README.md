# Automatic Parking Gate System

**Arduino-Based Automatic Parking Gate Using Ultrasonic Sensor**

This project demonstrates an automated parking gate system built with Arduino. The gate automatically opens when a vehicle is detected within a predefined distance using an ultrasonic sensor and closes after the vehicle passes, simulating a smart parking entrance system.

## Features

* Automatic vehicle detection using an ultrasonic sensor
* Servo motor-controlled gate operation
* Real-time distance measurement
* Fully automated opening and closing sequence
* Low-cost embedded system prototype

## Technologies

* Arduino
* Ultrasonic Sensor (HC-SR04)
* Servo Motor
* Arduino IDE
